# Installing Sidekick

Get Sidekick installed, connected to your Torn account, and ready to use in a few minutes.

<a class="store-button" href="https://chromewebstore.google.com/detail/sidekick/jipicbdlghbhnffmdlldfmemjjoeokji" target="_blank" rel="noopener">Install Sidekick from the Chrome Web Store</a>

## 1. Install Sidekick

1. Open the **Sidekick** listing in the Chrome Web Store using the button above.
2. Click **Add to Chrome**.
3. Confirm by clicking **Add extension** when Chrome asks for confirmation.
4. Once installation is complete, Sidekick is available from Chrome's extension toolbar.

Chrome's official guide: [Install and manage extensions](https://support.google.com/chrome/answer/2664769).

## 2. Pin Sidekick next to the address bar

Pinning Sidekick makes the extension immediately accessible from Chrome's toolbar.

1. Look to the right of the address bar and click the **Extensions** button (the puzzle-piece icon).
2. Find **Sidekick** in the list.
3. Click the **Pin** icon next to Sidekick.
4. The Sidekick icon will now stay visible in the toolbar next to the address bar.

You can drag pinned extension icons to change their order.

Chrome documents this under [Customise the Chrome toolbar](https://support.google.com/chrome/answer/14835450).

> **Recommended:** Keep Sidekick pinned. Most users will use the toolbar icon to open the Sidekick controls and access the sidebar.

## 3. Add your Torn API key

Many Sidekick modules use Torn's API to read live information. Set your API key once and the modules that require it can use the same key.

### Get your Torn API key

1. Open Torn's **API settings**: [Open Torn API settings](https://www.torn.com/preferences.php#tab=api)
2. Create an API key with the access level you want to use with Sidekick. The higher the access level, the more modules will work as intended. Your information never leaves your PC!
3. Copy the key.

### Add the key to Sidekick

1. Open **Torn.com**.
2. Click the **Sidekick** icon in Chrome's toolbar.
3. Open **Settings** using the gear icon.
4. Open the **API** section.
5. Paste your Torn API key into the API key field.
6. Save the setting if a save button is shown.

Once the key is stored, modules that require API access can use it without asking you to enter it again.

> **Security:** Treat your Torn API key like a credential. Do not post it in screenshots, Discord, GitHub, or support requests.

## 4. Keep the Sidekick control page handy

If you pinned Sidekick's plugin icon in the adress bar, you can control your modules and settings from any page! Just click on the Sidekick swiss armyknife icon and the controlpanel will open.

## 5. Start using Sidekick

After installation and API setup, open any Torn page and click the Sidekick icon.

From there you can:

- Open the Sidekick sidebar.
- Open **Settings** and configure modules.
- Toggle features from the extension controls.
- Add or manage sidebar modules.

Most Sidekick modules are opt-in, while a smaller set is enabled by default. See the module catalogue for the complete list and where each feature is configured.

[Browse the Sidekick Module Catalogue](README.md)

## Troubleshooting

### Sidekick is not visible in the toolbar

Open Chrome's **Extensions** menu and pin Sidekick. Chrome can hide installed extensions until you choose to pin them.

See [Install and manage extensions](https://support.google.com/chrome/answer/2664769).

### A module says an API key is required

Open **Sidekick → Settings → API** and check that a valid Torn API key has been entered. Some modules specifically require API access.

### Chrome will not install Sidekick

Make sure you are using desktop Chrome and are not trying to install the extension from Incognito or Guest mode. A work or school-managed browser may also restrict extension installation.

See Chrome's [extension troubleshooting guide](https://support.google.com/chrome_webstore/answer/1698338).
