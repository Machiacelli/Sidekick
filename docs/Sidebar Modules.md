# Sidekick Module Catalogue — Sidebar Modules

These modules live **inside the Sidekick sidebar** (the sliding panel you open on any Torn page). Add them via the sidebar's **+** button, right-click menus, or they appear automatically. Toggle behavior where noted comes from Settings or the toolbar popup.

---

## 📝 Notepad

Sticky notes inside the sidebar. Create as many notepads as you want, name them, and each one can be dragged around the Torn page and resized independently. Notes persist across sessions. Add from the sidebar **+ → Notepad**.

## ⏰ Timer

A countdown timer panel in the sidebar. The Timer module has no settings toggle — open the sidebar **+** menu to spawn a timer panel, then set title and duration in the panel itself. Panels survive page refreshes via the sidebar's window manager.

## 🕐 Clock

The clock display built into the sidebar top bar, showing Torn City Time alongside a points-market price readout (fetched live via your API key). No controls to find — when the sidebar is open, the clock is in its top bar by default.

## 🎪 Event Ticker

Where to find it: Settings → Events → **Event Calendar** (also toggleable from the toolbar popup) · Off by default · Lives in the sidebar top bar

Rolling event notifications between the sidebar clock and the Torn logo. Rotates through upcoming Torn events with a live countdown to the nearest one ("⏰ Next Event: CaffeineCon 2026 in 12d 03:44:49"), pulling dates from the official Torn calendar via API with a built-in list of holidays as fallback. Your personal event start time (events start at different times for each player) is respected.

## 🔗 Link Group

Where to find it: no settings toggle · Lives in the sidebar · Open sidebar **+ → Link Group**

Custom link collections. Build a box of your own quick-links to any Torn page and keep it in the sidebar. Box can be resized; order and size are shared across all your Torn tabs.

## ⚔️ Attack List

Where to find it: no settings toggle · Lives in the sidebar · Open sidebar **+ → Attack List**

Named lists of target IDs. Each target shows live status — Okay, Hospital, Jail, Away — with a color-coded countdown to leaving, refreshed every 5 minutes through the Torn API. Lists can be colored, renamed, pinned, dragged and resized within the sidebar.

## 📋 Todo List

Daily-task checklist in the sidebar. Tracks your daily energy/nerve refills, Xanax doses (4 per day maximum), bought items (100 per day), and prayers, and resets automatically each Torn day. Add from sidebar **+ → Todo List**. The refill/xanax checks use the API when a key is set.

## 📈 Stock Advisor

Where to find it: no settings toggle · Lives in the sidebar · Open sidebar **+ → Stock Advisor**

Stock perk analyzer with marginal ROI against your own settings — how much each extra share investment yields in dividend value, using the full perk table for all 35 Torn stocks. Includes its own settings for how you value energy, nerve, items, and other perk types.

## 💰 Debt Tracker

Where to find it: no settings toggle · Lives in the sidebar · Open sidebar **+ → Debt Tracker**

Tracks debts and loans you owe or are owed. Displays per-player panels with interest rules (none, daily, weekly, flat, APR), monitors payment logs via API to auto-detect partial payments, and can send payment-reminder messages. Pairs with Debt Receipt Sharing (see Economy & Market page).

## 💰 Travel Stocks

Where to find it: no settings toggle · Lives in the sidebar · Open sidebar **+ sidebar → Travel Stocks**

Abroad item stock price checker for every destination, pulled from YATA, with per-item cost, average sell price, profit margins, and buy-quantity sorting — green rows for profit, red for loss, tiered so standout deals pop. Toggles a "Show only profit" filter.

## 📊 Stats Tracker

Where to find it: no settings toggle · Lives in the sidebar · Open sidebar **+ → Stats Tracker**

Historical record of your battle stats. The window (resizable, draggable) shows gained/total per stat over selectable period (up to 90 days of history), letting you see growth trends without spreadsheets.

## 🏷️ Auction Tracker

Where to find it: no settings toggle · Lives in the sidebar (with a "Track" button on auction pages) · Open sidebar **+ → Auction Tracker**

Track auction-house listings without bidding on them. Use the "Track" button Sidekick adds next to any auction listing to add it to a live window showing bidder counts, current price (with last-price color coding), time left, per-bidder profit calc, and category color coding. Auto-refreshes every 60 seconds.
